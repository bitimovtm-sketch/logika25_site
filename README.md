# Новый сайт «Логика» (logika25.ru)

Статический сайт (HTML/CSS/JS) + один PHP-файл для приёма заявок в Битрикс24.

## Структура
- `site/` — **готовый сайт, его целиком загружаете на хостинг** (в корень домена).
- `build/` — генератор страниц (`node build/build.mjs`) и весь контент (`build/data.mjs`). Нужен только для правок текстов; на хостинг не загружается.
- `.claude/launch.json` — локальный предпросмотр (`python -m http.server 8080 -d site`).

## Запуск на хостинге
1. Загрузите содержимое папки `site/` в корень сайта (`public_html` / `www`).
2. Заявки → Битрикс24:
   - В Битрикс24: *Разработчикам → Другое → Входящий вебхук*, права **CRM**.
   - Скопируйте `api/config.sample.php` в `api/config.php`, вставьте URL вебхука (и при желании ID ответственного).
   - Нужен PHP 7.4+ с cURL. Если Битрикс24 недоступен, заявка уйдёт письмом на `fallback_email`.
3. Включите SSL (https). `.htaccess` уже содержит редирект на https, сжатие, кэш и 301-редиректы со старых адресов Tilda.
   Если на хостинге **Nginx** — перенесите правила редиректов из `.htaccess` в конфиг (список старых адресов — `OLD_URLS` в `build/data.mjs`), а `api/config.php` закройте от внешнего доступа.
4. Яндекс.Метрика: вставьте счётчик перед `</head>` в `build/build.mjs` (функция `layout`) и пересоберите.
5. После переноса домена проверьте `https://logika25.ru/sitemap.xml` и отправьте его в Яндекс.Вебмастер.
